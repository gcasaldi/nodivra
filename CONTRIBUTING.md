# Contributing to NODIVRA

I'd love to build NODIVRA with people who are curious about blockchain intelligence, OSINT, security, data visualization, and open-source development. You don't need to be an expert to contribute.

## Ways to help

- Improve wallet analysis and transaction tracing.
- Suggest reliable sources for publicly documented entity labels.
- Build clear graphs and investigator-friendly interfaces.
- Add tests, accessibility improvements, documentation, or thoughtful bug reports.
- Challenge assumptions and help distinguish evidence from speculation.

## Getting involved

Open an issue describing your idea or a reproducible problem, or propose a focused pull request. For larger changes, I'd appreciate an issue first so we can agree on the approach.

Please avoid posting private personal information, credentials, API keys, or unsupported accusations about wallet owners. Any attribution should be sourced, reviewable, and clearly marked as uncertain where appropriate.

This project is at an early stage. Thank you for helping shape it.

## Local preview

No build tools are needed for the current static preview. Serve the repository directory with a local HTTP server (for example, `python -m http.server 8000`) and open `http://localhost:8000/`.

The live wallet lookup uses the public Blockscout Ethereum API. Availability, rate limits, and cross-origin access depend on that service.
